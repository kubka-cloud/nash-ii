# НАШ Ии HTML-приложение




 ## Быстрый запуск







Откройте `index.html` в браузере на телефоне или компьютере.

Интерфейс адаптируется под экран смартфона.

В демо-режиме доступны экраны чата, видео, изображений, текстов, проектов и профиля.

- Проекты сохраняются локально в браузере через `localStorage`.



 ## Важно



Это HTML-прототип, а не полностью автономная нейросеть. В демо-режиме ответы и генерация являются демонстрационными. Для настоящего чата, изображений и генерации сценариев:



1. Запустите сервер из предыдущего архива `nash_ii_android_ios_fullstack.zip`.



 2. Разместите сервер на хостинге с HTTPS.

3. B `index.html установите `API_BASE в адрес сервера.

 4. Не вставляйте секретный АРІ-ключ непосредственно в HTML он должен храниться на сервере.



 Генерация часового видео не включена: сервер сейчас умеет составлять план на 60 минут, но реальный видеофайл требует видеопровайдера, фоновых задач и объединения сцен.



 ## Как разместить в интернете

 Можно разместить `index.html` на статическом хостинге. Если сайт доступен по HTTPS, сервер АРІ также должен иметь НТTPS и разрешать запросы с домена приложения (CORS).
